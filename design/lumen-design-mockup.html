Design notes

  
Environment is always visible. The colour of the line under the title bar, the card edge and the status bar dot all follow the connection's environment, so production never looks like local.

  
Edits are staged. Changed cells turn yellow, new rows green, deleted rows red and struck through. Nothing runs until the user reviews the generated SQL and commits.

  
Memory is on screen. The status bar shows the app's resident memory against its budget, a visible promise that the app stays small.

  
Native-friendly shapes. Every element here maps to GPUI primitives: divs with flex layout, uniform list for the virtualised grid, text runs for the editor. No web views.
